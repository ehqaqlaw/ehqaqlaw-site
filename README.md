# موقع إحقاق — النطاق العام (ehqaqlaw.sa)

هذا المستودع يخدم النطاق `ehqaqlaw.sa` عبر GitHub Pages. **الموقع تحت الإنشاء**: الصفحة الرئيسية الحالية صفحة تعريفية مختصرة (الشعار والعبارة التعريفية ورسالة «تحت الإنشاء»).

- `index.html` صفحة «تحت الإنشاء»
- `404.html` صفحة الخطأ
- `robots.txt` منع الفهرسة حتى الإطلاق
- `CNAME` ربط النطاق — لا يُمس
- `assets/` الشعار والأيقونة والأنماط (تُستخدم عند الإطلاق)

## بيئة الاختبار
الموقع الكامل يعمل للمراجعة الداخلية على المستودع `ehqaqlaw.github.io` (https://ehqaqlaw.github.io/) — غير مفهرس، ويُشارك رابطه داخلياً فقط. النسخة المصدرية المعتمدة للموقع الكامل محفوظة محلياً لدى الشركة.

## عند الإطلاق
1. رفع ملفات الموقع الكامل (النسخة المحلية) إلى جذر هذا المستودع مع استبدال `index.html` و`404.html` و`robots.txt`.
2. إبقاء `CNAME` كما هو.
3. التحقق من الصفحات على https://ehqaqlaw.sa ثم إرسال `sitemap.xml` إلى Google Search Console.
