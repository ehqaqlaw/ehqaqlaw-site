# موقع إحقاق — النطاق العام (ehqaqlaw.sa)

هذا المستودع يخدم النطاق `ehqaqlaw.sa` عبر GitHub Pages. **الموقع تحت الإنشاء**: الصفحة الرئيسية الحالية صفحة تعريفية مختصرة مع «دخول الأعضاء» لمعاينة الموقع الكامل قبل إطلاقه.

- `index.html` صفحة «تحت الإنشاء» + دخول الأعضاء (تحويل إلى بيئة المعاينة)
- `404.html` صفحة الخطأ
- `robots.txt` منع الفهرسة حتى الإطلاق
- `CNAME` ربط النطاق — لا يُمس
- `assets/img/` الشعار والأيقونة

## بيئة المعاينة
الموقع الكامل يعمل على المستودع `ehqaqlaw.github.io` (https://ehqaqlaw.github.io/) ويتطلب الدخول عبر «دخول الأعضاء» من الصفحة الرئيسية. النسخة المصدرية المعتمدة للموقع الكامل محفوظة محلياً لدى الشركة.

## عند الإطلاق
1. رفع ملفات الموقع الكامل (النسخة المحلية النظيفة، بلا سكربت المعاينة) إلى جذر هذا المستودع مع استبدال `index.html` و`404.html` و`robots.txt`.
2. إبقاء `CNAME` كما هو.
3. التحقق من الصفحات على https://ehqaqlaw.sa ثم إرسال `sitemap.xml` إلى Google Search Console.
